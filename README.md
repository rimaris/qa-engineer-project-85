# Codebattle — тестовый проект (QA)

Этот репозиторий посвящён тестированию проекта **Codebattle** — игры, где два программиста параллельно решают одну задачу на разных языках. Побеждает тот, кто первым проходит все тесты. Проект открыт и развивается силами комьюнити.

## Что тестируем
Ключевые возможности Codebattle:
- Дуэль на скорость: два редактора кода, общий прогресс и вывод тестов.
- Игра с человеком, ботом или другом (по ссылке).
- Выбор уровня сложности и/или конкретной задачи.
- Описание задач на русском и английском.
- Наблюдение за играми других пользователей.
- Чат для зарегистрированных пользователей.
- Повтор завершённых игр в режиме «проигрывателя».
- Начисление очков и рейтинги (неделя, месяц, всё время).
